## 📌 Overview
The **APAS (Agriculture & Horticulture Management System)** is an integrated software portal designed to assist agricultural advisory services, farm resource tracking, crop health monitoring, and horticultural yield management.

## ✨ Key Features
- 📊 **Crop & Soil Analytics**: Tools to track soil fertility parameters, crop recommendations, and seasonal data.
- 👨‍🌾 **Farmer Registration & Profiles**: Manage farmer identity records, landholdings, and crop cultivation data.
- 🌡️ **Weather & Pest Alerts**: Integrated notification insights for advisory alerts based on local weather conditions.
- 📑 **Report Generation**: Export statistical reports on yield output, subsidy distribution, and horticultural metrics.

## 🛠️ Tech Stack
- **Frontend**: React.js / HTML5 / CSS3 / JavaScript (ES6+)
- **Backend**: Node.js & Express API services
- **Database**: MongoDB / SQL data storage

## 🚀 Setup & Execution
1. Navigate to `backend` directory and run `npm install` followed by `npm start`.
2. Navigate to `frontend` directory and run `npm install` followed by `npm start`.
3. Access the web interface at `http://localhost:3000`.
